- **SHA-pin GitHub Actions** — only first-party `actions/*` are used; the
  user's SECURITY.md permits major-version tags for first-party actions. Not a
  finding.
- **SMTP CRLF/command injection** — gated: `lookupMX` derives the host via
  `Domain()`, whose anchored regex forbids CR/LF, so a malformed address
  returns false before any dial. Not exploitable as written.
- **`format.go:13` domain-literal char-class is slightly over-permissive**
  (`\x53-\x7f` overlaps `\x21-\x5a`, likely meant `\x5d-\x7f`) — faithful port
  of the upstream RFC/Elixir regex; only affects bracketed domain literals
  (vanishingly rare) and only makes them marginally more permissive. Not worth
  the risk of touching the regex.
- **Perf on the domain-list scans** — lists are ~38 entries; linear scan is
  irrelevant.
